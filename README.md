# 📝 Full-Stack Todo App (Firebase + AWS Deployed)

A modern full-stack Todo application built using React, TypeScript, and Firebase, with dual deployment on Firebase Hosting and AWS (EC2/S3) to demonstrate cloud deployment flexibility.

---

## 🚀 Live Deployments

- 🔥 Firebase Hosting: [Add Firebase link here](https://todo-firebase-d4265.web.app/)  
- ☁️ AWS EC2 Deployment: Deployed and tested on AWS EC2 instance (currently stopped to manage cost and resources)

---


## ✨ Features

- 🔐 Google Authentication using Firebase Auth
- 👤 User-specific task management (each user sees only their todos)
- ➕ Add new tasks
- ✔️ Mark tasks as completed
- 🗑️ Delete tasks
- ⚡ Real-time updates using Firestore
- 🌐 Dual cloud deployment (Firebase + AWS)
